環境変数のひな形（さんたく）

このファイルに実際の値は書いてありません。
= の右に、自分で用意した値を入れて使ってください。

Eclipse で動かす場合は、実行構成の Environment タブに1つずつ登録します。
コマンドで動かす場合は、set（Windows）や export（Mac / Linux）で設定します。

-----------------------------------------------------------------
GEMINI_API_KEY=
    Google AI Studio（https://aistudio.google.com/）で作る。
    無料枠で始められる。モデルは gemini-3.6-flash。

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
    Google Cloud Console の「APIとサービス → 認証情報」で
    OAuth 2.0 クライアント ID（ウェブアプリケーション）を作る。
    承認済みのリダイレクト URI に次を登録する。
      http://localhost:8080/login/oauth2/code/google

VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
    Web Push の鍵の組。次のどちらかで作る。
      ・npm の web-push コマンド  web-push generate-vapid-keys
      ・オンラインの VAPID 鍵生成ツール
    公開鍵は画面に出るが、秘密鍵は絶対に外に出さない。

DB_PASSWORD=
    MySQL の taskboard ユーザーのパスワード。
    prod（MySQL）で動かすときだけ必要。
-----------------------------------------------------------------

値を貼り付けるときの注意

  なぞって選ぶと末尾が欠けることがある。
  入力欄で Ctrl+A を押して全体を選んでから貼り付ける。
  VAPID の鍵が1文字でも欠けると
  「Incorrect length for uncompressed encoding」が出て起動しない。

共用のパソコンで使う場合

  Windows のユーザー環境変数に登録すると、使い終わっても値が残る。
  Eclipse の実行構成に入れる方法でも、ワークスペースの .metadata に
  平文で保存されるため、その場を離れるときは消しておく。
